Install `NineInnings26.ipa` with SideStore, AltStore, Impactor or Sideloadly, or add the source `https://github.com/benverhaalen/nine-innings-ios26/releases/latest/download/apps.json`.

On first launch tap **Download game**: the app fetches the original v6.0.7 APK from a public mirror, verifies its SHA-256, and plays offline from then on. This release contains no game files apart from the game's own icon.

New in 1.0.1:
- The original 9 Innings icon replaces the placeholder.
- **Download game** works hands-free: the mirror page stays hidden and its ads and trackers are blocked.
- First step of the replacement game server: the title screen's version check now succeeds.
