Install `NineInnings26.ipa` with SideStore, AltStore, Impactor or Sideloadly, or add the source `https://github.com/benverhaalen/nine-innings-ios26/releases/latest/download/apps.json`.

On first launch tap **Download game**: the app fetches the original v6.0.7 APK from a public mirror and verifies its SHA-256. This release contains no game files apart from the game's own icon.

New in 1.1.0: the online features work again, against a replacement server built into the app.
- HIVE login happens automatically with a local account.
- Daily login bonus, Mailbox and Tradebox, Online Ranking.
- Store and star items with Stars and Points you earn. Real-money packs are declined (earn-only).
- Card Market search, selling and buying.

Limitations: there are no other players (the server is local, so the market, gifts and rankings only know you). Star prices and bonus rewards are stand-ins for the unknown originals. There's no cloud save, and old Com2uS accounts can't be recovered. See the README's *Limitations* section.
